# La Chiave — site vitrine

Page d'accueil du Centro Linguistico La Chiave (Brazzaville & Pointe-Noire) : cours d'italien, test de niveau et préparation au visa d'études.

Site statique sans dépendance : ouvrir `index.html` ou le servir avec n'importe quel hébergeur statique (Vercel, Netlify, GitHub Pages).
